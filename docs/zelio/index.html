Support

ZELIO

仲間と合計距離を競う、チーム対抗ランニング・ウォーキングアプリのサポートページです。

お問い合わせ

ご意見・ご要望は、アプリ内の「ヘルプ・お問い合わせ」にあるフォームから お送りください。返信が必要な不具合の報告は、以下のGitHub Issuesをご利用ください。

不具合の場合は、発生日時、端末・OS、画面名、再現手順を添えてください。 パスワード、メールアドレス、GPSルートなどの個人情報・秘密情報は、 公開されるIssueへ記載しないでください。

GitHub Issuesを開く

安全に関する通報・ブロック

宣言、走行中表示、公開記録、チャレンジで不適切な内容を見つけた場合は、 アプリ内の対象付近にある「…」から理由を選び、運営へ非公開で通報してください。 同じ安全メニューからユーザーをブロックできます。

ブロック後は相手の投稿・ランキング・公開記録が非表示になり、相互の応援、 リアクション、関連通知も停止します。相手には通知されません。解除は 「プロフィール → ブロック中のユーザー」から行えます。 運営は、通報を原則24時間以内に確認開始し、規約に基づいて必要な措置を行います。

アプリ内で通報できない場合はGitHub Issuesからご連絡ください。ただし、個人情報や 通報対象の秘密情報は公開Issueへ記載せず、アプリ内通報を優先してください。

よくある質問

記録が増えません

GPSモードでは位置情報を許可し、空が見える場所でGPSの準備完了を待ってから 開始してください。歩数モードは端末のモーションセンサー対応が必要です。 通信できない場合も記録は端末に保管され、次回オンライン時に再送されます。

バックグラウンドで記録が止まります

位置情報を「常に許可」にすると、記録中のバックグラウンド計測を利用できます。 端末の省電力設定やアプリの強制終了により更新が止まる場合があります。 警告が表示された場合は、画面を開いたまま利用してください。

ZELIO Proを復元・解約できますか？

購入の復元は、アプリのプロフィールにある「購入を復元する」から行えます。 解約や支払い方法の変更は、App Storeのサブスクリプション設定から行ってください。

アカウントを削除できますか？

アプリのプロフィール画面から削除できます。削除後は活動、GPSルート、参加情報、 通知、バッジ、プロフィール画像を順次削除し、復元できません。

ランキングへ記録が反映されません

異常な速度、時刻、距離またはGPS精度として保留された可能性があります。 アプリを再起動しても解決しない場合は、発生日時と画面名を添えてお問い合わせください。
