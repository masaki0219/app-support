よくある質問

学習履歴はどこに保存されますか？

問題ごとの正解数、不正解数、最後に解いた日時などの学習履歴は、 原則として利用者の端末内に保存されます。

無料で利用できる問題はありますか？

全500問のうち、最初の15分野・60問を無料で利用できます。 残りの110分野・440問とプレミアム機能は、買い切り購入で利用できます。

プレミアム機能を復元できますか？

App StoreまたはGoogle Playで購入したプレミアム機能は、購入時と同じ ストアアカウントで復元できます。復元できない場合は、購入時のアカウントで サインインしているか確認してください。

公式問題や過去問題が含まれていますか？

収録問題は公開情報を参考に学習用として独自作成したもので、公式問題・過去問題・ 講習テキストを複製・転載するものではありません。実際の試験の出題内容、得点、 合格も保証しません。
