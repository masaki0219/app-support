よくある質問

どの試験に対応していますか？

CAD利用技術者試験の「2次元CAD利用技術者試験 2級」と「3次元CAD利用技術者試験 2級」の 2つの試験区分を、1つのアプリで学習できます。 各試験区分の問題は、公式の出題分野（2次元CADは「CADシステム」「製図」、 3次元CADは「概念」「機能と実用的モデリング手法」「データの管理と周辺知識」「データの活用」） に分けて収録しています。問題一覧の試験区分メニューから、試験区分ごとに絞り込んで学習できます。

購入の仕組みを教えてください。

試験区分ごとの買い切りで、購入した試験区分の全問題と、復習などの機能が期限なく使えます。 2つの試験区分をまとめて購入できるセットも用意しています。 試験区分の追加などに合わせて、購入できる商品の構成や価格を変更する場合があります。 購入済みの試験区分を利用する権利は、この変更によって失われません。

学習履歴はどこに保存されますか？

問題ごとの正解数、不正解数、最後に解いた日時などの学習履歴は、 原則として利用者の端末内に保存されます。

購入した試験区分を復元できますか？

App Storeで購入した試験区分は、同一のApple IDで復元できます。 復元できない場合は、購入時のApple IDでサインインしているか確認してください。

実際の試験問題が含まれていますか？

本アプリは学習支援を目的としたクイズアプリです。収録問題は、公開されている試験の概要や ガイダンスなどを参考に作成したオリジナルで、実際の試験問題の転載ではありません。 得点や合格を保証するものではありません。

試験の内容は変わることがありますか？

試験の出題範囲・問題数・試験時間・合格基準・試験方式などは、主催団体により変更される場合があります。 最新の情報は、主催団体の公式サイトでご確認ください。 変更があった場合は、アップデートで内容を見直します。
